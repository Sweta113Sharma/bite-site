undoCancellation window

How long a student has to undo a misclicked order and get an automatic refund.

seconds
This is also how long the canteen does not see the order. One number governs both halves on purpose. The outlet queue only shows a paid order once the window has closed, so staff can never start cooking something a student is still able to cancel out from under them.

Set it to 0 to switch cancellation off entirely. Students get no cancel button and the kitchen sees every order the moment it is paid for.

The default is 20 seconds, and the most you can set is 300. Longer than that and a student is waiting on food nobody has been told to cook yet.

Staff can still cancel and refund any order from the outlet portal at any time. This setting only governs what the student can do for themselves.

Takes effect immediately, including on orders already placed. Shortening the window can close it on an order still counting down, and hand that order straight to the kitchen. Lengthening it can pull a paid order back out of the outlet queue. An order the kitchen has already started is never affected either way: once it is being prepared it can no longer be cancelled by the student at all.
