Build the menu in a spreadsheet and upload it here. The canteen adds photos afterwards by editing items on its own menu screen, exactly as it would have anyway. Start from the template below if you have not done this before.

Saving as CSV: Excel — File → Save As → CSV UTF-8 (Comma delimited). Google Sheets — File → Download → Comma-separated values. Numbers — File → Export To → CSV.

The columns

The first row must be the header. Column order does not matter, the names are not case-sensitive, and any column not listed here is ignored.

ColumnRequiredWhat it meansExample
category Yes The section it appears under. Created automatically if new, in the order it first appears in the file. Max 80 characters. Snacks
item Yes The dish name, as students will see it. Max 150 characters. Wrap it in quotes if it contains a comma. "Chicken Roll, Large"
price Yes Rupees. A ₹ sign and thousands commas are fine and get stripped. Up to ₹99,999.99. 20 or ₹1,250.00
discount_price No A flat offer price. Must be below the price. Leave blank for none. 75.00
discount_percent No An offer as a percentage, between 0 and 100. Use this or discount_price, not both on the same row. 10
daily_limit No How many can be sold in a day before it shows as sold out. Whole number. Blank means no limit. 30
What the upload does
  • Preview first. The Preview button changes nothing. It shows every row it read, which items are new, and the old price beside any it would change. You then pick the same file again to import it for real.
  • Items are matched by name, ignoring case and extra spaces. An item that already exists is updated, so re-uploading a corrected file fixes prices instead of creating a second copy of the menu.
  • Nothing is ever deleted. An item missing from the file is left exactly as it is. To remove something, delete it on the canteen's menu screen.
  • Photos are never touched. Any picture the canteen has already uploaded survives a re-import.
  • Sold-out switches are respected. Updating an item does not put it back on sale; the canteen controls that from its own screen.
  • All or nothing. If any row has a problem, nothing is imported and every problem is listed with its line number, so one pass fixes the lot.
  • Up to 500 rows per file, and up to 5 MB.
